# 天津市中心妇产科医院《出生医学证明》办理流程

> 更新时间：2026-09-17 (UTC+8)

**点击上方蓝字可以订阅哟**

**尊敬的准妈妈、宝妈妈：**

您好! 感谢您到我院分娩。宝贝的降临,为你们的小家庭带来了更多的欢笑和幸福,在欣喜之余请不要忘记办理 《出生医学证明》，这是宝贝出生后获得的第一张证件，是重要的法律文书，承载很多社会功能，是户籍机关进行出生、人口登记、获得国籍、保健服务的重要凭证，请一定妥善保管，**千万不要遗失**。

**办理方式**：分为线上APP办理（推荐）及线下现场办理

**一、线上APP办理**：“津心办”APP 线上申报“出生一件事”，可实现新生儿的**出生医学证明、预防接种证、出生户口登记、医疗保险参保登记**以及**社会保障卡**事项的集成办理，避免您多次提交材料并且节省时间。
**01****办理对象**
①我院出生的一周岁以内的婴儿（2022年5月12日之后分娩）；

②父母双方现行婚姻关系内生育的子女；

③父母双方至少一方为天津市家庭户籍。

**0****2****办理时间**
自新生儿出生后一个工作日后，您可以随时通过“津心办”线上申报，网上申办完成后，一般1-5个工作日内由EMS投递。

**03****办理流程**
登录“津心办”，**新生儿母亲实名认证**，按照提示完成线上申领。详情请扫描下方二维码。

线上申领流程

**二、线下现场办理**

**（一）南开院区**
**0****1****办理对象**

在本院区分娩及不符合线上办理条件的人员。

**0****2****办理时间**

自新生儿出生后一个工作日后，您可以通过微信“天津中心妇产智慧服务”公众号进行预约。每周三、周五、周日 8:00-12:00；13:30-17:00（法定节假日除外）办理。

**0****3****办理材料**
①夫妻双方有效身份证原件及复印件；

②出生证微信预约凭证；

③新生儿母亲或父亲亲自办理为妥；委托他人办理需提供新生儿母亲亲笔填写的委托授权书及领证人的有效身份证件原件。委托书请扫描下方二维码。

代办人委托书模板

**04****办理地点**
天津市中心妇产科医院南开院区一楼住院大厅出生医学证明办理窗口。

**（二）和平院区**
**0****1****办理对象**

在本院区分娩及不符合线上办理条件的人员。

**0****2****办理时间**

自新生儿出生后一个工作日后，每周五13:30-16:30、周日 8:30-11:30办理。

**0****3****办理材料**
①夫妻双方有效身份证原件及复印件；

②新生儿母亲或父亲亲自办理为妥；委托他人办理需提供新生儿母亲亲笔填写的委托授权书及领证人的有效身份证件原件。委托书请扫描二维码（同南开院区）。

**04****办理地点**
天津市中心妇产科医院和平院区一楼大厅综合服务中心。

**温馨提示：**

1. 如您选择线下办理出生证，则**不能通过**线上APP“出生一件事”完成新生儿出生涉及的政务服务项目集成办理。

2. 建议父母在新生儿出生后**一个月内**办理出生证。依据《中华人民共和国户口登记条例》第七条规定。

3. 《出生医学证明》为重要法律文书，请**不要**在出生证上“画、涂、写”任何字迹，保管时应注意“防盗、防丢、防潮”，也不能塑封。申领到的《出生医学证明》副联存根**不要自行撕下** ，应该由户籍登记机关撕下，否则视为**无效**。

4. 如在办理过程中有疑问， 可拨打咨询电话：

**南开院区**：58287636，联系出生证办理处（除周六及法定节假日外8:00-12:00；13:30-17:00）。

**和平院区**：58971153，联系出生证办理处（工作日8:00-12:00；13:30-16:30）。

5. 换发及补证业务请周一至周五工作时间，于我院南开院区一楼住院大厅-出生医学证明办理窗口办理（法定节假日除外），地址：天津市南开区南开三马路156号，咨询电话58287636。 

6. 如有出生医学证明办理事宜调整，请您微信关注“天津中心妇产智慧服务”公众号信息发布。
